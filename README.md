# 重力陀螺 PINN · 0.5 秒版本

`gyro_pinn.pt` 是训练完成的模型。`predict.py` 可读取模型并预测 **[0, 0.5] 秒**内任意时刻的姿态矩阵、物体坐标系角速度和空间坐标系质心位置。两个文件放在同一目录，用已安装 PyTorch 的 Python 运行。

```powershell
python predict.py 0.3
```

省略时间参数时，可以在终端中输入时间。预测在 CPU 上运行。

## 训练和验证

使用 512 个物理残差计算点，先进行 1000 次 Adam 更新，再用最多 200 次 L-BFGS 迭代得到初步轨迹。精调阶段从这套权重出发，将角加速度残差的缩放分母从 600 调为 60，并用同一个 L-BFGS 优化器继续训练两轮，每轮最多 300 次迭代。SciPy 参考解使用 1001 个输出时刻，时间间隔为 0.0005 秒，用于验证。

| 指标 | 本次结果 |
|---|---:|
| 姿态角均方根误差 | 0.006171° |
| 最大姿态角误差 | 0.009098° |
| 角速度 x/z 分量均方根误差 | 0.000470 rad/s |
| 质心位置均方根误差 | 0.0781 mm |
| 0.5 秒时的质心位置误差 | 0.0372 mm |

`prediction_error.png` 显示三类误差随时间的变化。物理模型沿用题给惯性张量相对于质心的假设。
